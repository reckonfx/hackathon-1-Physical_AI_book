Glossary: Vision-Language-Action (VLA) Systems

This glossary defines key terms used throughout the VLA module.

A​

Action Planning: The process of converting high-level goals or commands into sequences of executable robot actions.

Action Sequencing: Organizing robot actions in a logical order to achieve a specific goal.

API (Application Programming Interface): A set of rules and protocols for building and interacting with software applications, such as the OpenAI API.

C​

Cognitive Planning: The use of artificial intelligence to interpret natural language commands and generate structured action plans for robots.

Computer Vision: A field of artificial intelligence that trains computers to interpret and understand the visual world.

D​

Deep Learning: A subset of machine learning based on artificial neural networks with representation learning.

Dialog System: A computer system designed to converse with humans in natural language.

E​

Embodied AI: Artificial intelligence systems that interact with the physical world through robotic bodies.

G​

Generative AI: AI systems that can generate new content, such as text, images, or other data.

Gripper: A device used on robotic arms to grasp and manipulate objects.

I​

Inverse Kinematics (IK): The mathematical process of determining the joint parameters needed to place a robotic arm's end effector at a specific position and orientation.

Intent Recognition: The process of identifying the underlying goal or purpose behind a natural language command.

K​

Kinematics: The branch of mechanics concerned with the motion of objects without reference to the forces that cause the motion.

L​

Large Language Model (LLM): A language model that contains many parameters and is trained on vast amounts of text data.

Latency: The time delay between a user's input and the system's response.

M​

Manipulation: The ability of a robot to physically interact with objects in its environment.

Motion Planning: The computational problem of finding a sequence of valid configurations to move an object from a starting state to a goal state.

N​

Natural Language Processing (NLP): A field of artificial intelligence focused on the interaction between computers and humans through natural language.

Navigation: The ability of a robot to move through its environment to reach desired locations.

O​

Object Detection: The computer vision technique of identifying and locating objects within an image or video.

OpenAI API: A set of interfaces provided by OpenAI to access their artificial intelligence models, including GPT and Whisper.

P​

Pose: The position and orientation of a robot or object in space.

Prompt Engineering: The practice of designing effective inputs for language models to generate desired outputs.

R​

Robot Operating System (ROS): A flexible framework for writing robot software that provides hardware abstraction, device drivers, and message passing.

ROS 2: The second generation of the Robot Operating System with improved architecture for real-world applications.

S​

Speech Recognition: The ability of a machine to identify and process human speech.

State Estimation: The process of determining the current state of a robot, including its position, orientation, and other relevant parameters.

V​

Vision-Language-Action (VLA): A system that connects visual perception, natural language understanding, and physical action in robotics.

Voice Command: A spoken instruction given to a computer or robot system.

W​

Whisper: OpenAI's speech recognition system that can transcribe audio to text and translate multiple languages to English.

Y​

YAML (YAML Ain't Markup Language): A human-readable data serialization language commonly used for configuration files in ROS and other systems.

Z​

Zero-Shot Learning: The ability of a model to perform tasks it hasn't been explicitly trained on, using its general understanding.

Acronyms and Abbreviations​

  • AI: Artificial Intelligence
  • API: Application Programming Interface
  • DOF: Degrees of Freedom (in robotics)
  • IK: Inverse Kinematics
  • LLM: Large Language Model
  • NLP: Natural Language Processing
  • ROS: Robot Operating System
  • VLA: Vision-Language-Action
